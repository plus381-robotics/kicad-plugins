# Plus381 KiCad plugins

## Install

In KiCad 10: **Plugin and Content Manager → Manage → +**, add this link and
click **Save**:

```
https://plus381-robotics.github.io/kicad-plugins/repository.json
```

Choose that repository in the drop-down, install the plugins you want and
click **Apply Pending Changes**.

## Plugins

| Plugin | What it does |
|---|---|
| [Plus381 Tools](plus381-tools/) | Shared parts library for the team: import parts (vendor zip or LCSC number) with a symbol, footprint and 3D preview, publish them to GitHub, and see a red dot when the team has new parts (one click to update). |
